# 数据隐私

处理个人信息时的合规与安全要求。当收集、存储、导出或删除用户数据时使用。

## 何时使用

- 新功能涉及个人信息
- 数据导出或对接第三方

## 步骤

1. 列出收集的字段与用途
2. 确认最小必要与告知同意
3. 定义保留期限与删除方式
4. 限制访问并记录访问日志

## 规则

- 只收集完成功能必需的字段
- 导出与日志都要脱敏
- 删除请求要覆盖备份与派生数据

## 红线

- 不把个人信息写进日志与测试数据
- 不超期保留
