# 集成测试

验证模块之间与外部依赖的协作。当单元测试通过但联调失败时使用。

## 何时使用

- 模块接口变更
- 对接数据库、队列、第三方服务

## 步骤

1. 确定真实依赖与替身边界
2. 用容器或内存实现替代外部服务
3. 每个用例独立准备与清理数据
4. 断言副作用而不只断言返回值

## 规则

- 测试要能重复执行且顺序无关
- 外部依赖失败路径也要覆盖
- 避免共享可变状态

## 红线

- 不让测试依赖生产数据
- 不用休眠等待异步结果
