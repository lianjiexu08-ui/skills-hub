# 端到端测试

从用户视角验证完整流程。当关键路径需要上线前确认时使用。

## 何时使用

- 核心流程上线前
- 跨服务改动

## 步骤

1. 只选 3-5 条最关键路径
2. 使用稳定选择器（语义/测试 ID）
3. 准备可重置的测试数据
4. 失败时保存截图与日志

## 规则

- 端到端测试要少而稳
- 不依赖执行顺序
- 失败信息要能直接定位

## 红线

- 不用坐标或文本样式定位元素
- 不把端到端当主要测试手段
