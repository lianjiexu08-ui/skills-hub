# API 文档

编写接口文档。当需要说明请求参数、响应结构、错误码与鉴权方式时使用。

## 何时使用

- 新增或修改接口后更新文档
- 对接方需要自助接入

## 步骤

1. 列出每个接口的方法、路径、鉴权要求
2. 逐个字段说明类型、必填、取值范围、默认值
3. 给出成功与失败的完整示例
4. 为每个错误码写明含义与处理建议

## 规则

- 字段说明与代码类型定义保持一致
- 示例响应必须是真实结构，不是示意
- 破坏性变更单独标注迁移方式

## 红线

- 不遗漏鉴权与限流说明
- 不用“自行理解”代替字段说明
