# 变异测试

检验测试是否真的能发现问题。当覆盖率很高但仍然漏 bug 时使用。

## 何时使用

- 怀疑测试有效性
- 关键模块质量加固

## 步骤

1. 在关键模块引入小变异（取反、换边界）
2. 运行测试，看是否有用例失败
3. 未被发现的变异说明断言不足
4. 补充针对性用例

## 规则

- 只对关键逻辑做变异测试
- 存活变异要分析原因
- 不追求 100% 杀死率

## 红线

- 不为提高杀死率写无意义断言
- 不对全仓库跑变异测试
