# 教程编写

编写循序渐进的教学内容。当需要带读者从零完成一个可运行成果时使用。

## 何时使用

- 新人上手路径
- 产品快速入门

## 步骤

1. 明确终点：读完能做出什么
2. 拆成每步都有可见结果的小节
3. 每节给出验证方式
4. 结尾给出扩展练习

## 规则

- 每步都可独立验证
- 失败路径也要说明
- 代码片段可整段复制运行

## 红线

- 不跳步
- 不留“此处省略”
