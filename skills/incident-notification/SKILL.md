# 事件通知

在数据或安全事件发生后按规定通知相关方。当需要履行通知义务时使用。

## 何时使用

- 数据泄露
- 重大服务中断

## 步骤

1. 确认是否触发通知义务与时限
2. 准备事实：影响范围、时间、数据类别
3. 按对象分别通知（用户/监管/合作方）
4. 记录通知过程与后续措施

## 规则

- 只陈述已确认的事实
- 不延迟也不夸大
- 保留通知记录

## 红线

- 不隐瞒已确认的泄露
- 不在未确认时发布推测性结论
