# 单课设计

设计一次教学或分享。当需要在一小时内讲清一个主题时使用。

## 何时使用

- 团队分享
- 单次培训

## 步骤

1. 定一个核心结论
2. 设计开场问题引发需求
3. 按“概念 → 例子 → 练习 → 小结”展开
4. 留出提问与练习时间

## 规则

- 一次只讲一个核心
- 例子要贴近听众场景
- 结尾回到核心结论

## 红线

- 不在有限时间塞过多内容
- 不只讲概念不练习
