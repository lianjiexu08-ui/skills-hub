# 移动端可访问性

让移动应用支持辅助功能。当需要通过无障碍要求或被用户投诉时使用。

## 何时使用

- 无障碍合规
- VoiceOver/TalkBack 支持

## 步骤

1. 为控件补充可读标签与角色
2. 检查焦点顺序与分组
3. 支持动态字体与对比度
4. 用读屏软件走关键流程

## 规则

- 图标按钮必须有标签
- 不只用颜色传达状态
- 支持系统字号缩放

## 红线

- 不移除系统提供的可访问性支持
- 不忽略读屏下的操作路径
