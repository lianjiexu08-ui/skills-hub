# 技术文档写作

撰写面向使用者的技术文档。当需要写功能说明、接入指南、操作手册或解释复杂机制时使用。

## 何时使用

- 为已有功能补文档
- 把口口相传的流程写成可执行说明

## 步骤

1. 确认读者是谁、要完成什么任务
2. 按“前提 → 步骤 → 结果 → 排错”组织
3. 每条命令可直接复制执行
4. 写完让不了解背景的人试跑一遍

## 规则

- 先写任务，再写机制；读者关心的是怎么用
- 命令与路径必须来自真实环境
- 示例用最小可运行版本，不写伪代码占位

## 红线

- 不写未验证的命令
- 不用“简单/显然”跳过关键前提
