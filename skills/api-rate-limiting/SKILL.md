# 限流与配额

保护系统与外部接口的调用量。当出现超限、被限流或成本失控时使用。

## 何时使用

- 第三方 API 限流
- 保护自身服务

## 步骤

1. 确认对方配额与计费方式
2. 实现令牌桶或滑窗限流
3. 超限时排队或降级而不是硬失败
4. 记录用量并设告警

## 规则

- 限流按资源维度区分
- 退避重试带随机抖动
- 配额剩余可观测

## 红线

- 不在超限时无脑重试
- 不让单一调用方占满配额
