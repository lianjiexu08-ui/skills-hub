# 威胁建模

在设计阶段识别安全风险。当新增系统、改动信任边界或做安全评审前使用。

## 何时使用

- 新系统设计
- 引入外部依赖或开放接口

## 步骤

1. 画出数据流与信任边界
2. 列出资产与攻击者能力
3. 按 STRIDE 等框架枚举威胁
4. 为每个威胁给出缓解措施与优先级

## 规则

- 先界定信任边界，再谈威胁
- 缓解措施要落到具体控制点
- 剩余风险要显式接受

## 红线

- 不只列清单不给措施
- 不假设内网可信
