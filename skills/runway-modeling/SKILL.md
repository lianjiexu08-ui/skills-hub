# 现金 runway 测算

估算现有资金能支撑多久。当需要判断资金安全与融资节奏时使用。

## 何时使用

- 融资规划
- 成本控制决策

## 步骤

1. 计算月均净现金消耗
2. 区分固定与可变成本
3. 按情景测算 runway
4. 识别可快速削减的支出

## 规则

- 用真实现金流而非会计利润
- 多情景测算
- 定期用实际数据更新

## 红线

- 不低估未来支出
- 不用乐观情景做唯一依据
