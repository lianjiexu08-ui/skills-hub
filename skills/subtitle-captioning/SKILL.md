# 字幕制作

制作准确易读的字幕。当视频需要无障碍或跨语言传播时使用。

## 何时使用

- 教程视频
- 多语言发布

## 步骤

1. 按语义断句，每行不超过合理长度
2. 校对专有名词与数字
3. 调整时间轴避免抢读
4. 检查多语言版本长度

## 规则

- 断句按意群而非字数机械切分
- 术语与正文统一
- 保留语气但去掉口头填充

## 红线

- 不漏译否定与数字
- 不出现遮挡画面的长行
