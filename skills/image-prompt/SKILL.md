# 图像提示词

编写可复现的图像生成提示。当需要稳定产出符合需求的配图时使用。

## 何时使用

- 文章配图
- 概念示意

## 步骤

1. 先定主体、场景、构图、风格
2. 用具体名词与形容词替代抽象词
3. 指定比例与光线
4. 固定种子或参考图保证一致性

## 规则

- 描述可观察的视觉特征
- 避免相互冲突的风格词
- 同一系列保持提示结构一致

## 红线

- 不使用真实人物肖像
- 不生成侵权或违规内容
