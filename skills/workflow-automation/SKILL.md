# 流程自动化

把重复的人工流程改造成自动执行。当同一套操作每周重复、容易出错时使用。

## 何时使用

- 重复的数据搬运与通知
- 人工审批链路

## 步骤

1. 画出当前人工流程与每一步输入输出
2. 找出可自动化的判定点与需要人确认的点
3. 先自动化最稳定的一段
4. 加失败告警与人工兜底

## 规则

- 保留人工介入的关键闸门
- 每步可观测可重试
- 失败要通知到人

## 红线

- 不自动化本就该人判断的决策
- 不留无告警的静默失败
