# 复盘主持

组织一次有产出的团队复盘。当迭代或项目结束需要改进时使用。

## 何时使用

- 迭代结束
- 重大事件后

## 步骤

1. 先回顾事实与时间线
2. 收集做得好与需改进项
3. 聚焦可改变的少数项
4. 产出带负责人与期限的行动

## 规则

- 对事不对人
- 行动项不超过 3 个
- 上次行动项先检查

## 红线

- 不让复盘变成追责
- 不产出无人跟进的动作
