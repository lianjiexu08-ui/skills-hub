# Webhook 设计

设计或接入事件回调。当系统之间需要异步通知时使用。

## 何时使用

- 对接第三方回调
- 对外提供事件通知

## 步骤

1. 定义事件类型与载荷结构
2. 签名并校验来源
3. 接收方快速返回 2xx 后异步处理
4. 实现幂等与重放保护

## 规则

- 回调必须验签
- 处理要幂等，防重复投递
- 失败可重试且可查

## 红线

- 不在回调里做长任务
- 不信任未验签的载荷
