# 分层解释

把复杂概念讲给不同背景的人。当需要向非专业者解释技术问题时使用。

## 何时使用

- 跨职能沟通
- 向管理层汇报技术方案

## 步骤

1. 先给一句话结论
2. 用类比建立直觉，再说明类比的边界
3. 按需要逐层补充机制细节
4. 确认对方卡在哪一层

## 规则

- 类比要标注不适用的地方
- 按对方提问深度决定展开程度
- 不省略关键限制

## 红线

- 不用类比替代准确说明
- 不因简化而说错
