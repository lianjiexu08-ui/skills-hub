# 财务汇报

向非财务人员说明财务状态。当需要向管理层或团队汇报经营情况时使用。

## 何时使用

- 月度经营会
- 预算执行汇报

## 步骤

1. 先给结论：是否健康、是否需要行动
2. 用 3-5 个关键指标说明
3. 解释偏差原因而非罗列数字
4. 给出建议与决策请求

## 规则

- 口径与上期一致
- 区分事实与预测
- 异常要有解释

## 红线

- 不用复杂表格掩盖问题
- 不遗漏重大风险
