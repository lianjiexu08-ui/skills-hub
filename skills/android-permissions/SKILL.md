# Android 权限

正确申请与处理运行时权限。当出现权限拒绝、上架被拒时使用。

## 何时使用

- 新增敏感权限
- 商店审核问题

## 步骤

1. 只申请功能必需权限
2. 在需要时申请并解释用途
3. 处理拒绝与永久拒绝分支
4. 提供降级功能

## 规则

- 最小权限
- 拒绝后功能要优雅降级
- 不在启动时批量申请

## 红线

- 不申请与功能无关的权限
- 不假设权限一定被授予
