# 运行手册

写出可被值班人员直接执行的处置步骤。当需要降低故障响应门槛时使用。

## 何时使用

- 建立值班流程
- 故障后发现处置依赖个人经验

## 步骤

1. 按症状组织（不是按系统）
2. 每条给出判定条件与具体命令
3. 写明风险与回退方式
4. 标注升级联系人与时限

## 规则

- 命令可直接复制执行
- 区分“先止血”与“再修复”
- 定期随架构更新

## 红线

- 不写“检查一下服务状态”这类空话
- 不省略回退步骤
