# 同期群分析

按时间或特征分组观察行为变化。当需要区分“整体增长”与“单群变差”时使用。

## 何时使用

- 留存看起来稳定但体感变差
- 评估改动对新老用户的不同影响

## 步骤

1. 按首次行为时间分组
2. 选统一观察窗口对齐比较
3. 看留存/转化随群次的变化
4. 拆分渠道与地区定位差异

## 规则

- 窗口必须对齐，否则不可比
- 区分新群变化与老群衰减
- 样本过小的群不单独下结论

## 红线

- 不混合不同观察长度比较
- 不用累计值掩盖单期下滑
