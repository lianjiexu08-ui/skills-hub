# 漏斗分析

定位流程中流失最严重的环节。当转化率低于预期、需要找出瓶颈时使用。

## 何时使用

- 注册/下单流程转化低
- 新版本上线后某步流失增加

## 步骤

1. 定义步骤与步骤间的判定事件
2. 确认同一用户在同一窗口内计数
3. 计算每步转化与流失
4. 对最大流失步骤做下钻（设备、渠道、版本）

## 规则

- 步骤定义必须互斥且可观测
- 区分“未到达”与“到达但失败”
- 与历史同期对比

## 红线

- 不把不同定义的事件串成漏斗
- 不忽略样本量小的步骤
