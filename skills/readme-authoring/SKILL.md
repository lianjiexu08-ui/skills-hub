# README 编写

编写项目 README。当新建仓库、接手项目或 README 已过期时使用。

## 何时使用

- 新项目起步
- README 与实际命令不一致

## 步骤

1. 一句话说明项目做什么、给谁用
2. 给出最短可运行的安装与启动命令
3. 列出验证方式（测试/构建命令）
4. 补充目录结构、配置项与常见问题

## 规则

- 把“能跑起来”的三条命令放在最前面
- 命令与实际 package scripts 一致
- 不写长篇架构介绍，放到 docs 里链接

## 红线

- 不放失效链接与过期截图
- 不承诺未实现的功能
