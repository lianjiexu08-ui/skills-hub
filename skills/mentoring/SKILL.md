# 带人辅导

帮助他人独立解决问题。当需要培养新人而非替他完成工作时使用。

## 何时使用

- 新人上手
- 团队能力建设

## 步骤

1. 先了解对方已尝试什么
2. 用提问引导而非直接给答案
3. 给可完成的小任务建立信心
4. 定期回顾成长与卡点

## 规则

- 目标是让对方下次能自己做
- 允许犯错但有安全边界
- 反馈及时且具体

## 红线

- 不直接接管对方任务
- 不把所有问题都替对方解决
