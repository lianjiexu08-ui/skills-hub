# 权限审查

定期检查谁拥有什么权限。当需要满足最小权限、清理离职与临时授权时使用。

## 何时使用

- 季度权限复核
- 人员变动后

## 步骤

1. 导出账号与角色清单
2. 对照岗位职责确认必要性
3. 清理长期未使用的授权与临时账号
4. 保留审查记录与审批

## 规则

- 默认最小权限
- 临时授权必须有过期时间
- 高权限操作要留审计

## 红线

- 不共享账号
- 不留无主的服务账号
