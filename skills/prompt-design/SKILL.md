# 提示词设计

为模型任务编写稳定可复现的指令。当输出不稳定、需要结构化结果时使用。

## 何时使用

- 结构化抽取
- 固定格式生成

## 步骤

1. 写清角色、任务、输入、输出格式
2. 给出正例与反例
3. 明确不确定时的行为
4. 用固定测试集验证

## 规则

- 输出格式可被程序解析
- 边界情况显式规定
- 提示变更要回归测试

## 红线

- 不依赖模型猜测缺失信息
- 不用模糊形容词代替规则
