# 响应式布局

让界面在不同尺寸下都可用。当移动端显示错乱、断点行为不一致时使用。

## 何时使用

- 多设备适配
- 新页面设计

## 步骤

1. 按内容需要定断点，而非照抄设备宽度
2. 移动优先确定最小可用布局
3. 处理长文本、超多列、固定宽度元素
4. 在真实设备或模拟器验证

## 规则

- 触控目标足够大且间距合理
- 不隐藏关键功能只做视觉收缩
- 横向滚动只在必要场景使用

## 红线

- 不假设所有用户用桌面
- 不只在大屏上验收
