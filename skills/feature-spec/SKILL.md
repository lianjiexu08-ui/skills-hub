# 功能规格

把需求细化为可实现的功能规格。当开发需要明确交互与数据规则时使用。

## 何时使用

- 需求进入实现阶段
- 多方对细节理解不一致

## 步骤

1. 列出所有状态与状态转换
2. 定义字段、校验、默认值
3. 写清权限与可见性
4. 给出边界与并发场景

## 规则

- 状态机优先于文字描述
- 每个字段有来源与去向
- 异常路径与主路径一起写

## 红线

- 不留“开发自行决定”的关键规则
- 不遗漏权限判断
