# 审计日志

记录关键操作以便追溯。当需要满足合规、排查越权或还原事故时使用。

## 何时使用

- 敏感操作审计
- 事故调查

## 步骤

1. 列出必须记录的操作（权限、数据、配置、导出）
2. 记录谁、何时、对什么、做了什么、结果
3. 日志防篡改并集中存储
4. 设定保留期与访问控制

## 规则

- 日志不包含敏感数据本体
- 失败尝试也要记录
- 日志写入不能影响主流程

## 红线

- 不记录后可修改
- 不遗漏失败与拒绝
