# 数据可视化

选择并制作能准确传达结论的图表。当需要汇报、解释趋势或对比时使用。

## 何时使用

- 汇报材料
- 探索性分析的结论呈现

## 步骤

1. 先写下要传达的一句话结论
2. 按关系选图：趋势用线、对比用条、分布用箱线/直方图
3. 去掉非数据墨水，标注单位与基线
4. 检查是否会被误读

## 规则

- 坐标轴从零开始（除非明确标注截断）
- 颜色用于区分而非装饰
- 一图一结论

## 红线

- 不用双轴误导相关性
- 不用饼图比较多类别
