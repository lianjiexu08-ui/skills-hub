# 对外发布

发布让它**离开本机**，性质从"操作"变成"对外承诺"。默认关闭，显式授权才做。

## 1. 先判断：这是不是发布

属于发布：

- 生成任何人可访问的链接。
- 上传到公共/共享存储、制品库、应用商店。
- 推送到外部仓库、发送到外部系统。

不属于：本地生成文件、写入工作目录。

## 2. 权限模型

- **默认不允许**自动发布。需要时由人显式开启对应能力。
- 权限是"允许这类动作"，不是"允许这次发布的内容"——**具体发布什么仍要按用户明确要求来选择**。
- 只发布用户点名的那一份，**不擅自扩大范围**（不"顺手把整个目录都传上去"）。
- 权限被拒绝时：**不要重试**，答案不会变；告知用户去哪里开启，或改为本地交付。

## 3. 内容检查（发布前）

- [ ] 不含密钥、令牌、内部地址、个人信息。
- [ ] 不含未脱敏的日志、堆栈、数据库内容。
- [ ] 外部资源用绝对地址或已内联；相对路径资源不会被一起上传。
- [ ] 文件是自包含的（单文件 HTML/文档），或依赖已确认可访问。
- [ ] 内容与用户要求一致，没有夹带未公开的改动。

## 4. 可撤销性

- 发布后要能**撤销或更新**，并保留记录（谁、何时、发布了什么）。
- 撤销能力不应被同一开关限制——即使发布权限关闭，仍应能下线旧链接。
- 记录发布 ID 与本地源文件路径的对应关系，便于后续更新。

## 5. 失败处理

- 权限关闭：停止并说明，不重试。
- 上传超限：改用工具提示的替代通道，或拆分/压缩。
- 并发发布被占用：等待当前发布结束再试，不并行强推。
- 结果不确定：先查发布列表确认是否已存在，再决定是否重发（避免重复公开）。

## 输出

```text
发布对象：<文件/制品>
可见性：<公开链接 / 内部 / 私有>
结果：<链接或 ID>
已检查：<脱敏项>
撤销方式：<如何下线>
```

## 红线

- 不在未授权时自动发布。
- 不发布未检查脱敏的日志或配置。
- 不因"上次可以"就跳过本次授权与检查。
- 不在结果不确定时重复发布，制造多个公开副本。
