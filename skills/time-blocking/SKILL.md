# 时间块安排

把任务安排到具体时间段。当总被会议打断、深度工作不足时使用。

## 何时使用

- 需要专注产出
- 会议占满日程

## 步骤

1. 先固定不可移动的会议
2. 为深度工作预留连续时间块
3. 把同类琐事批量安排
4. 留出缓冲与休息

## 规则

- 时间块要匹配任务类型
- 保护深度工作块不被打断
- 预留 20% 缓冲

## 红线

- 不把日程排到无缝
- 不在深度块里处理消息
