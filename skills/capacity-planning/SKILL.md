# 容量规划

预测并准备资源以支撑增长。当出现性能瓶颈或成本与容量失衡时使用。

## 何时使用

- 大促/活动前
- 资源利用率长期偏高或偏低

## 步骤

1. 测量当前峰值与增长趋势
2. 识别瓶颈资源（CPU/内存/连接/IO）
3. 按目标负载做压测验证
4. 制定扩容与限流预案

## 规则

- 按峰值而非均值规划
- 预留故障时的冗余
- 扩容方案要能快速执行

## 红线

- 不凭感觉估算容量
- 不在活动当天首次验证扩容
