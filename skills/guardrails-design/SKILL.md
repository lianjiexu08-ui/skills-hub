# 护栏设计

限制模型输出的风险。当模型会面向用户或触发外部动作时使用。

## 何时使用

- 对用户输出
- 模型调用外部工具

## 步骤

1. 列出不可接受的输出与动作
2. 用规则拦截（格式、关键词、权限）
3. 高风险动作要求人工确认
4. 记录拦截与放行日志

## 规则

- 规则优先于模型自评
- 拦截要有明确原因
- 高风险动作默认拒绝

## 红线

- 不只依赖提示词约束
- 不让模型自行决定权限
