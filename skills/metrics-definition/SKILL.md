# 指标定义

为业务指标建立唯一、可计算的定义。当出现同名指标口径不一致、需要统一统计方法时使用。

## 何时使用

- 多人报表数字对不上
- 新指标上线

## 步骤

1. 写清业务含义与判定条件
2. 定义分子、分母、时间窗、去重口径
3. 列出排除项（测试、内部、退款等）
4. 给出可执行的取数逻辑

## 规则

- 一个指标只有一个权威定义
- 口径变化必须记录版本与生效时间
- 同时给出可对比的历史口径

## 红线

- 不用“活跃用户”这类未定义词
- 不静默修改历史口径
