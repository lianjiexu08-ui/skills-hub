# 用户研究

通过访谈与观察获取真实需求。当需要理解用户行为而非意见时使用。

## 何时使用

- 需求真伪不明
- 设计改版前

## 步骤

1. 确定研究问题与目标人群
2. 设计开放式问题，问过去行为而非未来意愿
3. 记录原话与情境
4. 归纳模式并标注反例

## 规则

- 问“上次你怎么做的”，不问“你会不会用”
- 样本要覆盖边缘用户
- 区分事实与受访者解释

## 红线

- 不诱导提问
- 不把少数样本当普遍结论
