# 收件箱清零

系统处理消息与邮件。当信息渠道过多、重要事项被淹没时使用。

## 何时使用

- 消息积压
- 频繁漏回

## 步骤

1. 固定时段集中处理
2. 每条立即决定：回复、转任务、归档、删除
3. 需要跟进的转成有期限的任务
4. 关闭非必要通知

## 规则

- 一次处理不留未读
- 能两分钟解决的立即做
- 不把收件箱当待办清单

## 红线

- 不边处理边刷
- 不让重要消息只停留在收件箱里
