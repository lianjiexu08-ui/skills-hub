# 看板设计

设计用于决策的数据看板。当需要把指标组织成可读界面时使用。

## 何时使用

- 业务监控看板
- 汇报用数据页面

## 步骤

1. 先确定看板要支持什么决策
2. 按“结论 → 趋势 → 明细”分层
3. 每张图只回答一个问题
4. 标注口径、时间范围与更新时间

## 规则

- 少而准优于多而全
- 图表类型由数据关系决定
- 异常要有对比基准

## 红线

- 不堆砌无行动意义的指标
- 不用装饰性图表误导比例
