# 数据探索

快速了解一个陌生数据集的规模、分布与质量问题。当拿到新数据、需要判断能回答什么问题前使用。

## 何时使用

- 新数据集到手
- 结论异常需要回查数据

## 步骤

1. 看行数、列数、时间范围、主键唯一性
2. 逐列看类型、缺失率、取值分布
3. 找异常值与时序断点
4. 记录已知限制与不能回答的问题

## 规则

- 先看分布再看均值
- 缺失率高的列单独说明
- 所有结论标注样本范围与口径

## 红线

- 不在未检查数据质量前下结论
- 不忽略口径差异直接比较
