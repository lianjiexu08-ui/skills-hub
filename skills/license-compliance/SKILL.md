# 许可证合规

检查依赖或素材的许可证要求。当引入第三方代码或内容时使用。

## 何时使用

- 引入开源依赖
- 发布含第三方素材的产品

## 步骤

1. 列出所有第三方组件与许可证
2. 识别传染性许可证（如 GPL 类）
3. 检查署名与分发义务
4. 建立许可证清单并随版本更新

## 规则

- 许可证以实际文件为准
- 区分内部使用与对外分发
- 保留版权声明

## 红线

- 不假设“开源就能随便用”
- 不删除版权声明
