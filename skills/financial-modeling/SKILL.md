# 财务模型

建立可调的收支预测模型。当需要评估资金需求与情景影响时使用。

## 何时使用

- 融资或预算
- 评估增长投入

## 步骤

1. 从驱动因子出发（用户数、单价、转化率）
2. 分离假设与计算
3. 做基准/乐观/悲观三情景
4. 标注每个假设的依据

## 规则

- 所有数字可追溯到假设
- 不用单一情景做决策
- 定期用实际数据校准

## 红线

- 不隐藏关键假设
- 不把预测当承诺
