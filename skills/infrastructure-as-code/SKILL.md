# 基础设施即代码

用代码管理基础设施。当环境需要可复现、变更需要审查与回滚时使用。

## 何时使用

- 多云/多环境一致性
- 手工变更难以追踪

## 步骤

1. 把现有资源纳入代码管理
2. 按环境拆分变量与状态
3. 变更先 plan 再 apply
4. 状态文件加密并加锁

## 规则

- 禁止手工改生产资源
- 状态文件纳入远端存储并加锁
- 所有变更走代码评审

## 红线

- 不在未查看 plan 时 apply
- 不把密钥写进代码或状态
