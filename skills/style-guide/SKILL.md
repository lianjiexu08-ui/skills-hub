# 写作风格规范

为团队建立统一的写作规范。当多人产出文档、风格不一致、需要可执行的写作标准时使用。

## 何时使用

- 团队文档风格混乱
- 新人不知道该怎么写

## 步骤

1. 确定语气与读者假设
2. 规定术语、大小写、标点、标题层级
3. 给出正例与反例
4. 说明例外与豁免

## 规则

- 规则要可判定，不写“尽量专业”
- 每条规则配一个反例
- 控制篇幅，只写真正会用到分歧的点

## 红线

- 不制定无法执行的规则
- 不为了统一牺牲可读性
