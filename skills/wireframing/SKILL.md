# 线框设计

用低保真方式快速表达结构。当需要在投入视觉前对齐信息架构时使用。

## 何时使用

- 方案讨论初期
- 多方案快速比较

## 步骤

1. 先列页面要支持的任务与信息
2. 用方框与文字排出层级
3. 标注交互与状态变化
4. 与干系人确认结构再进入视觉

## 规则

- 刻意保持低保真，避免讨论配色
- 先结构后装饰
- 每个版本标注要解决的分歧

## 红线

- 不在结构未定前做高保真
- 不省略异常状态
