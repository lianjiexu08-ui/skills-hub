# 体验审计

系统评估一个流程的可用性。当转化低、用户抱怨“难用”时使用。

## 何时使用

- 关键流程转化下降
- 新用户上手困难

## 步骤

1. 走一遍真实任务路径并记录步数与耗时
2. 标记每处犹豫、歧义、额外输入
3. 与新用户一起观察（不引导）
4. 按影响排序问题

## 规则

- 以任务完成率为核心指标
- 区分可用性问题与视觉偏好
- 问题描述包含复现路径

## 红线

- 不把个人偏好当问题
- 不只看首页不看完整流程
