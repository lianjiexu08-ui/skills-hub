# 供应商评估

在采购前评估供应商风险。当需要引入外部服务处理业务或数据时使用。

## 何时使用

- 引入 SaaS
- 外包开发

## 步骤

1. 确认服务范围与 SLA
2. 评估数据位置、加密与访问控制
3. 检查退出与数据导出能力
4. 确认合规资质与事故通知机制

## 规则

- 数据可导出，避免锁定
- 事故通知有时限约定
- 明确责任边界

## 红线

- 不把核心数据交给无法导出的服务
- 不忽略子处理方
