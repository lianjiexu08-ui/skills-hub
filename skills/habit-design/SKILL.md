# 习惯设计

建立能持续的行为改变。当需要长期坚持某项实践时使用。

## 何时使用

- 建立写作/运动/学习习惯
- 改掉低效习惯

## 步骤

1. 选定最小可持续版本
2. 绑定到已有固定触发点
3. 降低启动成本并准备环境
4. 记录连续天数与中断原因

## 规则

- 从极小开始，先建立连续性
- 中断后次日恢复，不追求完美
- 用环境设计代替意志力

## 红线

- 不一上来就设定高强度
- 不因一次中断放弃
