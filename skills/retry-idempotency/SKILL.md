# 重试与幂等

安全地处理失败重试。当网络不稳定、需要保证不重复产生副作用时使用。

## 何时使用

- 调用外部接口
- 消息消费失败

## 步骤

1. 判断操作是否可安全重试
2. 为写操作引入幂等键
3. 采用指数退避加抖动
4. 设置最大次数与死信处理

## 规则

- 只对可重试错误重试
- 幂等键由业务唯一标识生成
- 重试要有上限与可观测

## 红线

- 不对非幂等写操作盲目重试
- 不无限重试
