# 数据清洗

处理缺失、重复、格式不一致与异常值。当原始数据无法直接分析时使用。

## 何时使用

- 导入外部数据
- 分析前发现脏数据

## 步骤

1. 先量化问题规模
2. 去重并确认业务主键
3. 统一格式与单位
4. 处理缺失：删除、填充或标注
5. 保留清洗前后对照

## 规则

- 每一步可追溯，不静默修改
- 填充值要有依据并记录
- 异常值先判断是否为真实业务现象

## 红线

- 不直接删除看不懂的数据
- 不覆盖原始数据且无备份
