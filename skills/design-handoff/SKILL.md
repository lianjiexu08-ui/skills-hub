# 设计交付

把设计准确交给实现方。当开发反复问细节、实现与设计偏差大时使用。

## 何时使用

- 设计进入开发
- 还原度验收

## 步骤

1. 标注间距、字号、颜色、圆角
2. 列出所有状态与交互（含空/错/加载）
3. 说明响应式与边界行为
4. 提供组件与资源文件

## 规则

- 标注使用设计系统的 token
- 异常状态必须交付
- 变更走版本记录

## 红线

- 不交付只有主态的稿
- 不用截图代替规格
