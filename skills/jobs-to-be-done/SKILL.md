# 待办任务分析

从用户想完成的任务出发定义需求。当功能越做越多但价值不清时使用。

## 何时使用

- 功能堆叠需要收敛
- 重新定位产品

## 步骤

1. 写清“当…时，我想…，以便…”
2. 列出当前替代方案与不满
3. 识别任务频率与重要性
4. 按任务而非功能组织方案

## 规则

- 任务描述不包含具体实现
- 关注动机与情境
- 同时考虑非消费场景

## 红线

- 不把功能名当任务
- 不忽略用户现有的土办法
