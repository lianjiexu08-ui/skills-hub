# 项目启动

在开始时对齐目标、范围与协作方式。当新项目立项、多方参与时使用。

## 何时使用

- 项目立项
- 跨团队合作开始

## 步骤

1. 明确目标、成功标准与不做什么
2. 确认角色与决策权
3. 约定沟通节奏与工具
4. 列出主要风险与依赖

## 规则

- 成功标准可验证
- 决策权必须明确到人
- 风险有人负责

## 红线

- 不在目标模糊时开工
- 不省略责任划分
