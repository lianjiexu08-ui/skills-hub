# 事实核查

在发布前核实关键陈述。当材料包含数字、引语或因果断言时使用。

## 何时使用

- 对外发布前
- 重要汇报

## 步骤

1. 逐条列出可核查的断言
2. 找到原始出处
3. 核对数字、时间、范围是否被误用
4. 标注无法核实的部分

## 规则

- 每个数字都要有出处
- 注意统计口径与样本范围
- 相关不等于因果

## 红线

- 不凭印象确认
- 不删除无法核实的句子就当作已核实
