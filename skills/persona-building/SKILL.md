# 用户画像

把研究结果整理成可用的用户模型。当团队对目标用户认知不一致时使用。

## 何时使用

- 设计评审缺少共同用户参照
- 增长策略需要分群

## 步骤

1. 按行为与目标分群，而非人口属性
2. 每组写清目标、阻碍、现有替代方案
3. 标注证据来源与样本量
4. 给出设计含义

## 规则

- 画像必须来自真实数据
- 分群数量控制在 3-5 个
- 每群说明不适用场景

## 红线

- 不编造用户故事
- 不用画像替代实际测试
