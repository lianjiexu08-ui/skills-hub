# 发布说明

撰写一次发布的对外说明。当需要向用户、客户或内部同步本次发布内容时使用。

## 何时使用

- 版本上线后对外同步
- 向非技术干系人说明变化

## 步骤

1. 一句话概括本次发布主题
2. 列出用户可感知的变化
3. 说明已知问题与规避方式
4. 给出反馈渠道

## 规则

- 面向结果而非实现
- 已知问题必须主动说明
- 与变更日志保持一致

## 红线

- 不夸大未验证的收益
- 不隐藏已知问题
