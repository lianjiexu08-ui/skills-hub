# 内容复用

把一份内容拆分适配多个渠道。当需要提高内容产出效率时使用。

## 何时使用

- 一次生产多平台分发
- 旧内容重新利用

## 步骤

1. 提取原文核心观点与证据
2. 按渠道特点重写而非直接搬运
3. 为每个渠道调整长度与格式
4. 保持事实与结论一致

## 规则

- 适配优先于复制
- 核心数据不得变形
- 标注来源与更新日期

## 红线

- 不直接复制粘贴到所有平台
- 不复用过期结论
