# 契约测试

保证服务提供方与使用方对接口理解一致。当多团队并行开发、接口频繁变更时使用。

## 何时使用

- 微服务接口协作
- 第三方 API 集成

## 步骤

1. 把接口契约写成可执行断言
2. 使用方定义期望，提供方验证实现
3. 契约变更走版本
4. 在 CI 中双向校验

## 规则

- 契约是双方共同维护的产物
- 破坏性变更必须提前通知
- 契约要与文档同步

## 红线

- 不让契约只存在于文档
- 不单方面修改字段语义
