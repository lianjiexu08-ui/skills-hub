# 合同审阅

在签署前识别合同中的关键风险条款。当需要审阅服务、采购或合作合同时使用。

## 何时使用

- 签署前审阅
- 对方模板需评估

## 步骤

1. 确认主体、范围、期限与费用
2. 重点看责任、赔偿、终止、知识产权条款
3. 标记模糊或单方有利表述
4. 整理需谈判的条款清单

## 规则

- 不确定的条款提出澄清而非假设
- 关注默认续约与自动扣费
- 保留书面变更

## 红线

- 不代替专业法律意见
- 不忽略责任上限与数据条款
