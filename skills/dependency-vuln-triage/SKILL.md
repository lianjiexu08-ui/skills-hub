# 依赖漏洞分级

判断漏洞告警是否需要立即处理。当扫描报告大量告警、需要排优先级时使用。

## 何时使用

- 依赖扫描告警
- 安全公告影响评估

## 步骤

1. 确认漏洞是否在可达代码路径上
2. 确认受影响版本范围
3. 评估利用条件与网络暴露面
4. 决定升级、缓解或接受风险

## 规则

- 可达性优先于 CVSS 分数
- 无补丁时给出临时缓解
- 接受风险要记录理由与期限

## 红线

- 不只凭分数批量升级
- 不忽略间接依赖
