# 供应链安全

降低第三方依赖与构建流程被投毒的风险。当引入依赖、发布产物时使用。

## 何时使用

- 引入新依赖
- 发布可执行产物

## 步骤

1. 锁定依赖版本与来源
2. 启用完整性校验（哈希/签名）
3. 审查构建脚本与安装钩子
4. 生成并保存构建来源信息

## 规则

- 不使用来源不明的包
- 构建环境最小化且可复现
- 发布产物可追溯到提交

## 红线

- 不执行未经审查的安装脚本
- 不关闭完整性校验
