# 备份与恢复

设计并验证数据备份。当需要保证数据可恢复、满足保留要求时使用。

## 何时使用

- 建立备份策略
- 事故后恢复数据

## 步骤

1. 确定 RPO/RTO 目标
2. 选择全量+增量策略与保留周期
3. 备份加密并异地存放
4. 定期做恢复演练并记录耗时

## 规则

- 未验证的备份不算备份
- 恢复演练要覆盖到应用可用
- 备份与源数据隔离权限

## 红线

- 不只备份不演练
- 不把备份放在同一故障域
