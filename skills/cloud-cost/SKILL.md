# 云成本优化

找出并降低不必要的云支出。当账单异常增长或需要预算控制时使用。

## 何时使用

- 月度成本复盘
- 成本突然上涨

## 步骤

1. 按服务/环境/标签拆解成本
2. 找空闲资源、过量规格、无生命周期存储
3. 评估预留/竞价等计费方式
4. 设定预算告警与责任归属

## 规则

- 先归因再优化
- 优化不能牺牲可用性目标
- 所有资源必须有成本标签

## 红线

- 不为省钱降低关键冗余
- 不删除来源不明的资源
