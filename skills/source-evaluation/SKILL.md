# 来源评估

判断一条信息是否可信。当需要引用外部资料或核查说法时使用。

## 何时使用

- 引用数据或结论前
- 信息相互矛盾

## 步骤

1. 确认作者与机构资质
2. 看是否有原始数据与方法
3. 检查发布时间与版本
4. 寻找独立来源交叉验证

## 规则

- 原始来源优于转述
- 有利益相关要标注
- 无法验证时明确说明

## 红线

- 不引用无法追溯出处的数字
- 不把营销材料当研究
