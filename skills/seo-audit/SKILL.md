# SEO 审计

检查站点在搜索引擎中的可见性问题。当自然流量下降或新站需要优化时使用。

## 何时使用

- 自然流量下滑
- 内容站上线

## 步骤

1. 检查可抓取性与索引状态
2. 检查标题、描述、结构化数据
3. 检查内链结构与重复内容
4. 分析关键词覆盖与排名变化

## 规则

- 先解决技术性阻碍再做内容
- 内容质量优先于关键词堆砌
- 变更后观察足够周期

## 红线

- 不使用作弊手段
- 不一次性大改导致排名波动
