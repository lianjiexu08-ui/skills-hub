# 压力测试

验证系统在目标负载下的表现。当需要确认容量、找出瓶颈时使用。

## 何时使用

- 大促前容量验证
- 性能优化后回归

## 步骤

1. 定义目标负载与成功标准（延迟、错误率）
2. 准备接近真实的测试数据与场景
3. 从低负载逐步加压
4. 记录瓶颈资源与拐点

## 规则

- 测试环境要接近生产规格
- 关注 p95/p99 而非均值
- 区分容量瓶颈与代码缺陷

## 红线

- 不用生产环境直接压测
- 不以单次结果下结论
