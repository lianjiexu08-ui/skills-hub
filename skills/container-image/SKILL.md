# 容器镜像构建

构建小而安全、可复现的镜像。当镜像过大、构建慢或存在安全风险时使用。

## 何时使用

- 新服务容器化
- 镜像漏洞扫描告警

## 步骤

1. 使用多阶段构建，只保留运行时产物
2. 固定基础镜像版本（不用 latest）
3. 以非 root 用户运行
4. 使用 .dockerignore 减小上下文

## 规则

- 构建可复现：锁定依赖版本
- 不在镜像里放密钥与源码历史
- 减少层数与体积

## 红线

- 不用 latest 作为基础镜像
- 不以 root 运行生产容器
