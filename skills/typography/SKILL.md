# 排版

设置可读的字体与文本样式。当长文阅读疲劳、界面文字不协调时使用。

## 何时使用

- 内容型页面
- 建立文字样式规范

## 步骤

1. 按用途选字体与字号阶梯
2. 设定行高与字距（正文行高约 1.5）
3. 控制每行字符数（中文约 30-40 字）
4. 建立标题层级与段落间距

## 规则

- 正文字号不小于可读下限
- 层级之间差异明显
- 中英文混排注意间距

## 红线

- 不用过多字重与字体
- 不为了美观牺牲可读性
