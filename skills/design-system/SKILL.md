# 设计系统

建立可复用的组件与样式规范。当界面开始不一致、多人协作需要共同语言时使用。

## 何时使用

- 多页面风格漂移
- 新成员需要快速产出

## 步骤

1. 盘点现有组件与重复样式
2. 定义颜色、字号、间距、圆角的基础刻度
3. 抽象组件 API（变体、尺寸、状态）
4. 给出使用示例与禁止用法

## 规则

- 基础刻度有限且成比例
- 组件覆盖状态而非只做主态
- 变更走版本与迁移说明

## 红线

- 不为一次性需求新增变体
- 不让组件库与实现脱节
