# SQL 查询

编写正确且可维护的查询。当需要从关系库取数、排查统计口径、优化慢查询时使用。

## 何时使用

- 取数分析
- 核对指标口径

## 步骤

1. 先确认表关系与粒度（一行代表什么）
2. 用 CTE 分步构建，每步可单独验证
3. 先小范围验证再全量
4. 检查行数是否符合预期

## 规则

- 明确 JOIN 是否放大了行数
- NULL 参与比较要显式处理
- 时间范围用半开区间避免边界重复

## 红线

- 不在未确认粒度时聚合
- 不用 SELECT * 作为交付查询
