# 渗透测试规划

组织一次授权的安全测试。当需要评估系统实际攻击面时使用。

## 何时使用

- 上线前安全验证
- 合规要求

## 步骤

1. 明确范围、时间窗、禁止操作
2. 准备测试账号与环境
3. 按攻击面设计用例（认证、注入、越权、文件、SSRF）
4. 输出可复现的问题与修复建议

## 规则

- 必须有书面授权
- 测试数据与生产隔离
- 不进行破坏性测试除非明确授权

## 红线

- 不在无授权时测试
- 不泄露测试中获取的数据
