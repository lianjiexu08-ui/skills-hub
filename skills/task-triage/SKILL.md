# 任务分诊

快速决定任务做、拖、转、丢。当待办堆积、优先级混乱时使用。

## 何时使用

- 待办列表失控
- 多来源任务冲突

## 步骤

1. 逐条判断：必须我做吗、现在做吗
2. 两分钟内能完成的立即做
3. 可委派的写清要求后转出
4. 不做的明确删除并说明

## 规则

- 每条任务有明确下一步动作
- 委派要给出验收标准
- 删除比堆积更有效

## 红线

- 不把“以后再说”当处理
- 不让任务停留在模糊描述
