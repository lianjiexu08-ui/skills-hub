# 知识库构建

把零散信息整理成可检索的知识体系。当团队重复回答同类问题、经验无法沉淀时使用。

## 何时使用

- 新人上手成本高
- 资料分散在聊天记录里

## 步骤

1. 按使用场景而非部门分类
2. 每篇只解决一个问题
3. 建立索引与交叉链接
4. 设定更新责任人与过期标记

## 规则

- 可检索优先于完整
- 一条信息只在一处维护
- 过期内容要标记而非堆积

## 红线

- 不复制粘贴形成多个版本
- 不建无维护人的知识库
