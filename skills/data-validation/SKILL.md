# 数据校验

为数据管道或报表建立校验规则。当需要防止错误数据流入下游时使用。

## 何时使用

- 数据入仓或对外输出前
- 指标突然变化需要定位

## 步骤

1. 定义必须成立的约束：非空、唯一、范围、外键
2. 设置总量与分布的对账点
3. 校验失败时阻断并告警
4. 记录每次校验结果

## 规则

- 校验规则要能定位到具体行或字段
- 对账比绝对值更可靠
- 规则变化要版本化

## 红线

- 不只校验格式不校验业务含义
- 不让校验失败静默通过
