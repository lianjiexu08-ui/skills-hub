# 本地化

让产品适配目标地区。当涉及日期、货币、时区、文案长度与文化差异时使用。

## 何时使用

- 进入新市场
- 界面文本在别的语言下溢出

## 步骤

1. 列出所有用户可见文本与格式
2. 处理日期、数字、货币、时区
3. 预留文案变长空间
4. 检查图标、颜色、示例的文化适配

## 规则

- 格式由地区决定，不硬编码
- 文案长度按最长语言设计
- 示例数据也要本地化

## 红线

- 不假设所有地区都用同一日期格式
- 不直译文化特定表达
