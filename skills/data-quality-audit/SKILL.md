# 数据质量审计

系统检查一批数据的可信度。当数据用于对外发布或重大决策前使用。

## 何时使用

- 对外发布数据前
- 指标异常需要判断是数据问题还是业务问题

## 步骤

1. 检查完整性、唯一性、及时性、一致性
2. 抽样人工核对关键字段
3. 对比上游源与下游报表
4. 输出问题清单与影响范围

## 规则

- 抽样要有随机性与覆盖度
- 区分数据缺陷与业务真实变化
- 所有结论附核对方法

## 红线

- 不在未核对的情况下对外发布
- 不掩盖已知数据缺陷
