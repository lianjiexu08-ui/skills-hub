# 每日计划

安排一天的工作重点。当任务多、容易被打断时使用。

## 何时使用

- 每天开工前
- 感觉忙但没进展

## 步骤

1. 列出今天必须完成的 1-3 件事
2. 为每件事预留不被打断的时间块
3. 把琐事集中处理
4. 收工前记录完成与未完成原因

## 规则

- 按影响而非紧急排序
- 预留应对突发的时间
- 未完成要分析原因而非直接顺延

## 红线

- 不排满到没有余量
- 不把待办清单当计划
