# 用户手册

编写面向最终用户的操作手册。当产品需要自助上手、减少支持成本时使用。

## 何时使用

- 新功能上线需要用户自助学习
- 客服重复回答同类问题

## 步骤

1. 按用户目标组织章节，而非按界面结构
2. 每节包含：适用场景、操作步骤、预期结果
3. 补充常见错误与解决方式
4. 提供快捷键与进阶技巧

## 规则

- 用用户的语言，不用内部术语
- 截图或示意与当前版本一致
- 步骤可被非专业用户照做

## 红线

- 不假设用户懂技术背景
- 不使用过期界面截图
