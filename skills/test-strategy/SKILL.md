# 测试策略

为一个项目确定测什么、测到哪一层。当测试零散、不知道覆盖是否足够时使用。

## 何时使用

- 新项目建立测试
- 测试成本高但问题仍多

## 步骤

1. 列出关键用户路径与高风险模块
2. 按层级分配：单元覆盖逻辑、集成覆盖契约、端到端覆盖关键路径
3. 确定不测的部分及理由
4. 设定质量门禁

## 规则

- 测试投入与风险成正比
- 关键路径必须有自动化
- 宁可少而稳，不要多而脆

## 红线

- 不追求覆盖率数字
- 不只做端到端
