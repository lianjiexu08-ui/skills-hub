# 验收标准

把需求转成可执行的验收条件。当开发与测试对"做完"理解不一致时使用。

## 何时使用

- 需求进入开发前
- 验收争议

## 步骤

1. 按场景写 Given/When/Then
2. 覆盖主流程、异常与边界
3. 每条附检查方式
4. 与产品、开发共同确认

## 规则

- 每条标准可被自动或手动验证
- 包含失败与权限场景
- 避免实现细节

## 红线

- 不写"功能正常"
- 不遗漏异常路径
