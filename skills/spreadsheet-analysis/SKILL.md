# 表格分析

用电子表格完成数据整理与分析。当数据规模不大、需要快速核对或交付时使用。

## 何时使用

- 业务方需要自己维护的分析
- 快速核对数据

## 步骤

1. 把原始数据单独放一张表，不改原表
2. 用公式而非手工值构建结果
3. 加校验行（合计、计数）
4. 冻结表头并标注口径

## 规则

- 原始数据与结果分离
- 公式可向下复制，不硬编码行号
- 关键单元格加说明

## 红线

- 不在原始数据上直接覆盖计算
- 不留手工改过的“最终版”多个副本
