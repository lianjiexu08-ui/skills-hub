# 界面评审

评审界面实现的视觉与交互质量。当需要判断“做得对不对、好不好用”时使用。

## 何时使用

- 设计稿实现后验收
- 上线前质量检查

## 步骤

1. 对照设计稿检查间距、字号、颜色、圆角
2. 检查各状态：空、加载、错误、超长文本
3. 检查多尺寸与暗色模式
4. 检查键盘与焦点

## 规则

- 先看一致性与层级，再看细节
- 异常状态与主状态同等重要
- 指出问题给出具体位置与建议

## 红线

- 不说“感觉不好看”而无具体依据
- 不忽略空状态与错误状态
