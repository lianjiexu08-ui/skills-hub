# 文献综述

系统梳理一个领域已有工作。当需要找到研究空白或技术现状时使用。

## 何时使用

- 技术方案调研
- 学术或专利写作

## 步骤

1. 定义检索范围与关键词
2. 建立纳入/排除标准
3. 按主题归类并提取方法、数据、结论
4. 指出分歧与空白

## 规则

- 记录检索式与筛选过程
- 不遗漏反例与失败案例
- 区分作者结论与你的推断

## 红线

- 不只读摘要下结论
- 不隐瞒矛盾结果
