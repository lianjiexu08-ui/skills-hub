# 异步沟通

写出不依赖即时回复的沟通内容。当跨时区、跨团队协作时使用。

## 何时使用

- 远程协作
- 减少会议

## 步骤

1. 标题写清需要对方做什么
2. 给出背景、选项、建议与截止
3. 明确回复方式与紧急程度
4. 需要时附材料链接

## 规则

- 一条消息一个议题
- 明确期望的回应
- 不假设对方有上下文

## 红线

- 不用“在吗”开场
- 不把决策藏在长文末尾
