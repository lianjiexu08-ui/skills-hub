# 通知路由

把不同事件发送给正确的人与渠道。当告警太多没人看、重要信息被淹没时使用。

## 何时使用

- 告警分级
- 多团队协作通知

## 步骤

1. 按严重度与归属定义路由规则
2. 合并同类通知避免刷屏
3. 高优先级用即时渠道，低优先级汇总
4. 提供静音与升级机制

## 规则

- 每条通知可行动
- 通知量要可控
- 升级路径明确

## 红线

- 不对所有事件用同一渠道
- 不发无人负责的通知
