# 翻译

在保持原意的前提下翻译内容。当需要跨语言传达技术或产品信息时使用。

## 何时使用

- 文档多语言
- 对外沟通材料

## 步骤

1. 先通读，确定术语与语气
2. 建立术语表并全文统一
3. 按目标语言习惯重构句子，而非逐词对应
4. 回读检查是否有漏译与歧义

## 规则

- 术语一致优先于字面忠实
- 代码、命令、变量名不翻译
- 保留原文的限定与否定范围

## 红线

- 不漏译否定与条件
- 不改动代码与配置示例
