# 视觉层级

让界面一眼看出主次。当信息拥挤、用户找不到重点时使用。

## 何时使用

- 页面信息过多
- 关键操作不突出

## 步骤

1. 列出信息优先级（1-3 级）
2. 用字号、字重、间距、颜色建立层级
3. 限制同一屏的强调元素数量
4. 眯眼测试：是否还能看出主次

## 规则

- 优先级靠对比而非堆装饰
- 同一层级使用同一视觉语言
- 留白也是层级工具

## 红线

- 不同时使用过多强调手段
- 不让所有元素都“重要”
